# SweatLock Landing Page

## Files
- `index.html` — full marketing / converting landing page (dark theme, primary `#14ec5b`)
- `logo.svg` — full app icon (512 viewBox) — sweat droplet + lock
- `logo-mark.svg` — small mark for nav / favicon

## Preview locally
```bash
open landing/index.html
# or
npx serve landing
```

## App icon
Export `logo.svg` to PNG at 1024×1024 for App Store / Play Store, then generate density assets.

## Store links
Replace `#download` button hrefs in `index.html` with real App Store / Play Store URLs when live.
